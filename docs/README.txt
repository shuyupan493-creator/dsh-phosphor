换图时的规则：

1. 【不要出现工作区名、会话标题、消费金额】—— 侧栏那种列表最容易带出来。
   上一版就因为侧栏拍到了课程名、翻译项目、酒馆工作区而不能用。
2. 【不要把街机拍进去】—— 它是彩蛋。README 里只写"自己找"，图里更不能给。
3. 主界面的处理：从整窗截图裁掉顶部菜单栏（y < 44）；状态栏保留，那是主题的一部分。
4. 设置面板原样即可，但确认顶部能看到 PHOSPHOR 那一行和版本号。
5. 【换图要换文件名】。GitHub 的图片缓存按 URL 存，同名替换后页面仍会显示旧图
